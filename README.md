# SPK COCOSO

Aplikasi web Sistem Pendukung Keputusan (SPK) yang mengimplementasikan metode CoCoSo (Combined Compromise Solution) untuk membantu proses perangkingan alternatif berdasarkan beberapa kriteria dan sub-kriteria.

Fitur
Manajemen data kriteria & sub-kriteria
Manajemen data alternatif
Proses perhitungan otomatis dengan metode CoCoSo
Dashboard hasil perangkingan
Autentikasi login untuk admin
<br>Tech Stack</br>
PHP (CodeIgniter 3)
MySQL
Bootstrap, jQuery
<br>Cara Menjalankan</br>
Clone/download repo ini
Import file database/db_cocoso1.sql ke MySQL
Sesuaikan koneksi database di application/config/database.php
Jalankan di local server (XAMPP/Laragon), arahkan ke folder project
